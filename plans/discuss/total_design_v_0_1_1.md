1. 能运行、能对战（最重要）
2. 能分享给朋友试玩（次重要）
3. 有简单的 UI、美术（也验证大模型做美术设计的能力）

### AI 参与范围：

- **一人公司模式**：大模型全负责（策划、代码、美术等）
- 人类角色：提供想法、监督结果

## 三、Demo 阵营选择

| 决策 | 理由 |
|-----|------|
| 君主制 vs 封建制 | 机制相对简单，易于上手；可测试"多胜利条件"设计 |

### 选择理由：

1. 君主制机制相对简单（君主核心 + 效忠），易于上手
2. 封建制有独特的土地胜利条件，可测试"多胜利条件"设计是否成立
3. 两者的光谱位置接近，光谱影响相对较小，减少干扰
4. 可测试"防守反击型"（君主制保君主）vs"铺场型"（封建制抢格子）的对局节奏

## 五、光谱机制定位

| 决策 | 说明 |
|-----|------|
| 接受光谱是"次要机制" | 弱化存在感，不影响核心玩法 |

### 具体措施：

- 减少对光谱的 UI 强调
- 将光谱影响设定为"微调"而非"决定性因素"
- 在卡牌设计时，让大部分卡牌不依赖光谱

## 六、战争阶段体验优化

| 决策 | 说明 |
|-----|------|
| 增加情绪锚点 | 提升战争阶段的参与感 |
| 不允许干预 | 保持"命令 → 执行"的核心设计 |

### 情绪锚点设计建议：

- 显示"预测结果"：在命令下达阶段，显示"如果你下达这个命令，预计会发生什么"
- 显示"关键事件提示"：在执行时，高亮显示关键事件（如"君主被攻击！""捕获成功！"）
- 增加"即时回顾"：执行结束后，提供本回合关键决策的反馈

## 十、游戏逻辑测试清单

### 一、基础规则测试

| 编号 | 测试项 | 预期结果 |
|-----|-------|---------|
| B-01 | 黄金每回合充满 | 第 N 回合黄金上限 = N（最高 10） |
| B-02 | 每回合抽 2 张牌 | 手牌数 +2 |
| B-03 | 手牌上限 10 张 | 超出时无法抽牌/弃牌 |
| B-04 | 牌库 50 张用尽 | 弃牌堆洗入牌库 |
| B-05 | 人口 ≤0 判负 | 立即结束游戏 |
| B-06 | 回合开始时结算利息 | 资本主义专属 |

### 二、单位行动测试

| 编号 | 测试项 | 预期结果 |
|-----|-------|---------|
| U-01 | 单位横向移动 | 成功移动到目标格 |
| U-02 | 单位纵向移动（后排→中排） | Rank 1 优先执行 |
| U-03 | 单位纵向移动（中排→前排） | Rank 2 优先执行 |
| U-04 | 单位纵向移动（前排→中排） | Rank 3 优先执行 |
| U-05 | 单位纵向移动（中排→后排） | Rank 2 优先执行 |
| U-06 | 单位向后移动 | 移动前后均不可攻击 |
| U-07 | 一个命令包含移动+攻击 | 成功执行 |
| U-08 | 一个命令超过一次移动+攻击 | 不应被允许 |
| U-09 | 每单位每回合最多一个部署命令 | 第二个命令应被拒绝 |

### 三、攻击与反击测试

| 编号 | 测试项 | 预期结果 |
|-----|-------|---------|
| A-01 | 单位 A 攻击单位 B | 双方扣除相应攻击力的血量 |
| A-02 | 单位被攻击时反击 | 反击造成伤害 |
| A-03 | 反击次数 | 无限制 |
| A-04 | A 攻击 B，B 反击杀死 A | 同时结算，A 的攻击生效 |
| A-05 | 远程攻击（炮兵） | 可以攻击非相邻单位 |
| A-06 | 建筑被攻击 | 不反击 |

### 四、命令系统测试

| 编号 | 测试项 | 预期结果 |
|-----|-------|---------|
| C-01 | 战术阶段时限 3 分钟 | 时间到自动进入战争阶段 |
| C-02 | 提前结束战术阶段 | 可手动确认进入战争阶段 |
| C-03 | 放置单位到己方后排空位 | Rank 1，成功放置 |
| C-04 | 放置单位到己方后排有单位的位置 | 放置失败 |
| C-05 | 放置单位到对手后排空位 | Rank 3，成功放置 |
| C-06 | 放置建筑到任意位置 | 建筑不可移动 |
| C-07 | 事件卡使用 | 按事件效果执行 |

### 五、冲突规则测试

| 编号 | 测试项 | 预期结果 |
|-----|-------|---------|
| F-01 | 双方同 Rank 放置到同一后排格 | 后排所有者优先，后者返回手牌 |
| F-02 | 双方同 Rank 放置到同一中排格 | 双方放置，触发对峙攻击 |
| F-03 | 单位 A 已在位置，B 行进到该位置 | 按 Rank 顺序，或同 Rank 同时攻击 |
| F-04 | 双方同 Rank 纵向移动到中排同一格 | 互相攻击，存活者占据 |
| F-05 | 连锁死亡结算 | 每步骤结束即结算，人口回合末扣除 |

### 六、撤退机制测试

| 编号 | 测试项 | 预期结果 |
|-----|-------|---------|
| R-01 | 前排撤退到中排空位 | 成功撤退 |
| R-02 | 中排撤退到后排空位 | 成功撤退 |
| R-03 | 后排撤退 | 不允许 |
| R-04 | 撤退后攻击 | 本回合不能攻击 |
| R-05 | 攻击后撤退 | 本回合不可撤退 |
| R-06 | 撤退目标位置有单位 | 撤退失败 |

### 七、君主制专属测试

| 编号 | 测试项 | 预期结果 |
|-----|-------|---------|
| K-01 | 首回合自动抽君主卡 | 牌库中君主卡被抽到 |
