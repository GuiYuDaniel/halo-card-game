# 封建制阵营卡牌数值设计 v0.1.0

**日期：** 2026-06-29
**状态：** Demo 版本设计完成

---

## 概述

本文档记录封建制阵营 Demo 版本的完整卡牌设计，采用渐进式披露形式：从基础规则 → 词条系统 → 卡牌清单，逐层展开。

---

## 第一层：基础规则

### 1.1 移动与攻击

| 原始命令 | 判定条件 | 实际执行 |
|---------|---------|---------|
| 移动 | 目标位置已有对方单位 | 转变为攻击 |
| 攻击 | 目标位置无单位 | 转变为移动 |

**简化核心**：移动和攻击统一为一个操作，根据目标位置自动判定。攻击后不占领目标位置。

### 1.2 回合结构

- **回合** = 回合开始 → 战术阶段 → 战争阶段 → 回合结束（一次循环）
- **命令** = 战术阶段或战争阶段对一个单位的全部计划部署
- 战术阶段下达命令，战争阶段执行双方命令

### 1.3 封建制阵营特色（不写卡牌，写在阵营规则中）

| 特色名 | 效果 |
|-------|------|
| 领地连锁 | 横向相邻建筑单位，每回合结束时回复 1 血量 |
| 开拓 | 纵向相邻单位，每回合结束时 +1 生命上限 |
| 土地胜利 | 控制 15 ± 光谱修正 个格子，连续 2 回合则获胜 |
| 建筑特性 | 所有建筑单位不可移动 |

### 1.4 基础数值规则

| 项目 | 数值 |
|-----|------|
| 黄金上限 | 第 N 回合 = N（最高 10） |
| 每回合抽牌 | 2 张 |
| 手牌上限 | 10 张 |
| 牌库数量 | 固定 50 张 |
| 人口基础值 | 100 |
| 战术阶段时限 | 3 分钟 |

## 第五层：关键机制说明

### 5.1 领地连锁运作

- **触发时机**：每回合结束时
- **条件**：建筑单位在同一排（同一 Rank）横向相邻
- **效果**：该建筑回复 1 血量
- **封地加成**：拥有封地词条的建筑，触发领地连锁时额外回复 1 血量（共 2 血量）
- **叠加**：多个建筑形成横向链条，每个建筑各自触发

### 5.2 开拓运作

- **触发时机**：每回合结束时
- **条件**：单位在同一列纵向相邻（即上下相邻）
- **效果**：该单位 +1 最大生命上限（当前血量不增加）
- **适用范围**：所有己方单位（含建筑），只要有纵向相邻友方单位

### 5.3 土地胜利判定

- **触发时机**：每回合结束时
- **条件**：己方控制 ≥ 15 ± 光谱修正 个格子
- **连续判定**：需连续 2 回合满足条件
- **控制定义**：格子上有己方单位（含建筑）即视为控制

### 5.4 宣言触发规则

- 只有**部署**的卡牌才执行宣言
- 被召唤/拉出的单位（如农奴开垦召唤的农奴、征召令召唤的农奴）不执行宣言
