# 君主制阵营卡牌数值设计 v0.1.0

**日期：** 2026-04-10
**状态：** Demo 版本设计完成

---

## 概述

本文档记录君主制阵营 Demo 版本的完整卡牌设计，采用渐进式披露形式：从基础规则 → 词条系统 → 卡牌清单，逐层展开。

---

## 第一层：基础规则

### 1.1 移动与攻击

| 原始命令 | 判定条件 | 实际执行 |
|---------|---------|---------|
| 移动 | 目标位置已有对方单位 | 转变为攻击 |
| 攻击 | 目标位置无单位 | 转变为移动 |

**简化核心**：移动和攻击统一为一个操作，根据目标位置自动判定。攻击后不占领目标位置。

### 1.2 回合结构

- **回合** = 回合开始 → 战术阶段 → 战争阶段 → 回合结束（一次循环）
- **命令** = 战术阶段或战争阶段对一个单位的全部计划部署
- 战术阶段下达命令，战争阶段执行双方命令

### 1.3 君主制阵营特色（不写卡牌，写在阵营规则中）

| 特色名 | 效果 |
|-------|------|
| 君主核心 | 君主只能放在每排中间位置（第 4 格），不可主动移动，对方不可放置或移动至此位置（可攻击）。首回合自动从牌库抽取一张君主，放置在本方后排 4 号位置。君主被消灭后，连续 2 回合无新君主则判负。君主可以攻击。 |
| 王不见王 | 如果有一张君主在场，则对方不可再放置同名君主（首回合自动抽取除外） |
| 效忠 | 君主相邻两格有己方非建筑单位时，有概率替君主抵挡伤害。基础概率 50%，受光谱修正。效忠成功时，额外触发此单位所有被动 1 次。 |

### 1.4 基础数值规则

| 项目 | 数值 |
|-----|------|
| 黄金上限 | 第 N 回合 = N（最高 10） |
| 每回合抽牌 | 2 张 |
| 手牌上限 | 10 张 |
| 牌库数量 | 固定 50 张 |
| 人口基础值 | 100 |
| 战术阶段时限 | 3 分钟 |

| RTv1_11 | 征税 | 获得 1 黄金 |

## 第五层：关键机制说明

### 5.1 效忠机制运作

- **触发条件**：君主相邻两格有己方非建筑单位
- **基础概率**：50%，受光谱修正
- **效忠成功效果**：
  1. 该单位替君主抵挡伤害
  2. 额外触发此单位所有被动 1 次

### 5.2 宣言触发规则

- 只有**部署**的卡牌才执行宣言
- 被召唤/拉出的单位（如"漂亮姑娘"、"万里长城"）不执行宣言

### 5.3 光谱修正

| 光谱等级 | 相对红色方 | 相对蓝色方 |
|---------|-----------|-----------|
| ±3 | +30% | -30% |
| ±2 | +20% | -20% |
| ±1 | +10% | -10% |
| 0 | 基准 50% | 基准 50% |
