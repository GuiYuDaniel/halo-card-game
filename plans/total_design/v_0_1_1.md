# 第 1 层：快速上手

## 一、游戏是什么

- **类型**：1v1 意识形态题材战棋卡牌游戏
- **模式**：支持 PvE 和 PvP
- **节奏**：耐玩慢节奏（单局 15～30 分钟）

## 二、怎么赢

| 胜利条件 | 说明 |
|---------|------|
| **消灭对手** | 对手人口≤0 |
| **君主崩溃** | 对手君主被消灭后，连续 2 回合无新君主 |
| **土地胜利** | 封建制控制 15±光谱修正 格连续 2 回合 |

## 三、每回合做什么

```
1. 回合开始：充满黄金，抽 2 张牌
2. 战术阶段：下达多个命令（时限 3 分钟，可提前结束）
3. 战争阶段：按命令顺序自动执行
4. 回合结束：结算利息等效果
```

## 四、核心特色

1. **三排战棋**：后排×2 + 中排公共，共 21 格
2. **命令系统**：战术阶段自由下达多个命令
3. **光谱机制**：意识形态动态影响战局
4. **五大阵营**：奴隶制、君主制、封建制、资本主义、社会主义

# 第 2 层：基础规则

## 二、战场与基础规则

### 2.1 战场布局

```
                    玩家 B 后排 (B 的 Rank 1 / A 的 Rank 3)
┌─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│  B1 │  B2 │  B3 │  B4 │  B5 │  B6 │  B7 │
├─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│  M1 │  M2 │  M3 │  M4 │  M5 │  M6 │  M7 │  ← 中排 (双方 Rank 2)
├─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│  A1 │  A2 │  A3 │  A4 │  A5 │  A6 │  A7 │
└─────┴─────┴─────┴─────┴─────┴─────┴─────┘
                    玩家 A 后排 (A 的 Rank 1 / B 的 Rank 3)

总计：3 排 × 7 列 = 21 格
```

### 2.2 资源系统

| 资源 | 说明 |
|-----|------|
| **黄金** | 主资源 1，每回合自动填满上限（1→2→...→10），用于打出手牌 |
| **人口** | 主资源 2，基础值 100。单位被消灭时扣除对应人口，人口≤0 判负 |
| **手牌** | 每回合自动抽取 2 张，手牌上限 10 张 |
| **牌库** | 固定 50 张 |

### 2.3 命令类型

| 命令类型 | 说明 |
|---------|------|
| **放置单位命令** | 将单位（建筑或非建筑）放置到场内 |
| **策划事件命令** | 对场内单个或多个单位发动事件 |
| **部署非建筑单位命令** | 指挥已存在的非建筑单位行动（每单位每回合最多一次命令） |

### 2.4 单位行动基本规则

| 规则 | 说明 |
|-----|------|
| **战术阶段时限** | 3 分钟，可提前结束 |
| **命令内容限制** | 一个命令最多包含一次移动和一次攻击 |
| **反击机制** | 单位被攻击时自动反击（次数不限） |
| **移动方向** | 可横向或纵向移动 |
| **向后移动惩罚** | 向后移动的单位，移动前后均不可攻击 |

### 2.5 Rank 优先级规则

> **适用条件**：仅在**同命令顺位**的情况下使用。

| 移动类型 | 执行 Rank |
|---------|----------|
| 放置 → 自己后排 | Rank 1（最先） |
| 纵向移动：后排 → 中排 | Rank 1 |
| 纵向移动：中排 → 前排 | Rank 2 |
| 纵向移动：前排 → 中排 | Rank 3 |
| 纵向移动：中排 → 后排 | Rank 2 |
| 横向移动（中排内） | Rank 2 |
| 放置 → 对手后排 | Rank 3（最后） |

# 第 3 层：核心机制

## 三、意识形态光谱

### 3.1 光谱设计

```
    相对红色侧                      相对蓝色侧
    ◄─────────────────────────────────►
   +3   +2   +1    0   -1   -2   -3
    红   红   红    白   蓝   蓝   蓝
```

| 颜色 | 游戏内含义 |
|-----|----------|
| 红色 | 相对红色侧 |
| 蓝色 | 相对蓝色侧 |
| 白色 | 中立（0） |

### 3.2 五大阵营历史时期

| 阵营 | 最早出现世纪 |
|-----|------------|
| 奴隶制 | 公元前 35 世纪 |
| 君主制 | 公元前 32 世纪 |
| 封建制 | 公元 9 世纪 |
| 资本主义 | 公元 16 世纪 |
| 社会主义 | 公元 19 世纪 |

> **相对性判断**：世纪数值更小（更早）= 相对蓝色；世纪数值更大（更晚）= 相对红色

### 3.3 光谱效果

| 光谱等级 | 相对红色方效果 | 相对蓝色方效果 |
|---------|--------------|--------------|
| ±3 | +30% | -30% |
| ±2 | +20% | -20% |
| ±1 | +10% | -10% |
| 0 | 基准 50% | 基准 50% |

### 3.4 光谱移动规则

| 来源 | 触发条件 | 移动方向 |
|-----|---------|---------|
| 奴隶制 | 成功奴役一个单位 | 向奴隶制的相对方向 -1 |
| 资本主义 | 触发经济危机 | 向资本主义的相对方向反向 -1 |
| 镜像对战 | 双方同阵营 | 不移动 |

## 四、五大阵营核心机制（概览）

### 4.1 奴隶制（公元前 35 世纪）
- **捕获**：消灭单位有概率捕获，成功奴役后光谱向相对方向移动
- **人海**：非建筑单位费用 -1，血量上限 -1

### 4.2 君主制（公元前 32 世纪）
- **君主核心**：君主只能放第 4 格，被消灭后 2 回合无新君主则判负
- **效忠**：相邻非建筑单位有概率替君主挡刀（基础 50%）

### 4.3 封建制（公元 9 世纪）
- **领地连锁**：横向相邻建筑每回合回复 1 血量
- **开拓**：纵向相邻单位每回合 +1 生命上限
- **土地胜利**：控制 15±光谱修正 格连续 2 回合获胜

### 4.4 资本主义（公元 16 世纪）
- **利息**：未使用黄金的 50% 作为利息（经济危机回合不生效）
- **经济危机**：人口越低负面效果越强，触发时光谱反向移动

### 4.5 社会主义（公元 19 世纪）
- **计划经济**：每 5 回合预览牌堆顶 3 张并排序
- **同志**：1 血受伤单位攻击力翻倍
- **支援**：后排单位每回合给同列前方单位 +2 攻击/-1 血量

# 第 4 层：详细设计

## 四、五大阵营核心机制（详细）

### 4.1 奴隶制（公元前 35 世纪）

**核心机制：**

| 机制 | 详细设计 |
|-----|---------|
| **捕获（奴役）** | 消灭对手单位后有概率捕获为己用。基础概率 50%，受光谱修正。成功奴役后，光谱向本次对战中奴隶制的相对方向移动 -1 |
| **人海** | 非建筑单位费用 -1（最低 1），血量上限 -1 |

**特色卡牌示例：**
- 「奴隶主」(3 费，2/4，1 人口)：每回合可尝试奴役一个受伤单位
- 「角斗场」(4 费，建筑，2 人口)：相邻单位捕获率 +5%
- 「斯巴达克斯」(6 费，5/6，1 人口)：消灭的单位 50% 概率捕获

---

### 4.2 君主制（公元前 32 世纪）

**核心机制：**

| 机制 | 详细设计 |
|-----|---------|
| **君主核心** | 君主只能放在每排中间位置（第 4 格），不可主动移动。首回合自动从牌库抽取一张君主，放置在本方后排 4 号位置。君主被消灭后，连续 2 回合无新君主则判负 |
| **王不见王** | 如果有一张君主在场，则对方不可再放置同名君主（首回合自动抽取除外） |
| **等级压制** | 阵营卡牌费用≥5 的单位超模约 10-15% |
| **效忠** | 君主相邻两格有己方非建筑单位时，有概率替君主抵挡伤害。基础概率 50%，受光谱修正 |

**君主卡牌设计原则：**
- 费用：不按标准模型，按历史影响力设计
- 血量：参考实际存活年龄（如 38 岁≈4 血）
- 攻击：0-10，主要参考战争能力，次要参考个人战力
- 人口：固定 1
- 特效：参考生平事迹和主要历史贡献

**君主卡牌示例：**
- 「维多利亚」(1 费，0/8，1 人口)：每回合 +1 黄金
- 「秦始皇」(6 费，10/5，1 人口)：建筑单位 +2 血量
- 「路易十六」(2 费，2/4，1 人口)：每回合只能被攻击一次，但有 10% 几率直接被攻击死亡

---

### 4.3 封建制（公元 9 世纪）

**核心机制：**

| 机制 | 详细设计 |
|-----|---------|
| **领地连锁** | 横向相邻建筑单位，每回合回复 1 血量 |
| **开拓** | 纵向相邻单位，每回合 +1 生命上限 |
| **土地胜利** | 控制 15 ± 光谱修正 个格子连续 2 回合获胜 |
| **建筑特性** | 所有建筑单位不可移动（通用特性） |

**特色说明：**
- 鼓励建筑之间的连锁机制
- 需要精心布局，占据中排向对手延伸
- 唯一有特殊胜利条件的阵营

---

### 4.4 资本主义（公元 16 世纪）

**核心机制：**

| 机制 | 详细设计 |
|-----|---------|
| **利息** | 每回合结束，未使用黄金的 50% 作为利息（向下取整）。受光谱修正。经济危机触发回合不生效 |
| **收购** | 「收购」卡：支付原价黄金购买对手单位，人口归属己方 |
| **经济危机** | 人口每向下一个阶段，触发一次经济危机。危机触发回合利息不生效 |
| **危机循环** | 每使用一次经济危机卡，光谱向相对方向反向移动 -1 |

**资本主义经济危机效果：**
| 人口区间 | 负面效果 |
|---------|---------|
| 70-100 | 无影响 |
| 50-69 | 利息收益 -1 |
| 30-49 | 无法使用「收购」卡 |
| 10-29 | 所有单位攻击力 -1 |
| 1-9 | 每回合额外失去 2 人口（经济崩溃） |

**特色卡牌示例：**
- 「银行」(2 费，建筑，2 人口)：每回合 +1 利息收益
- 「垄断巨头」(7 费，5/5，1 人口)：登场时可以购买一个对手费用 ≤3 的单位
- 「人为危机」(2 费，事件)：触发一次经济危机。失去 2 黄金上限，抽一张卡

---

### 4.5 社会主义（公元 19 世纪）

**核心机制：**

| 机制 | 详细设计 |
|-----|---------|
| **平均分配** | 多种效果卡：①平均场上数值 ②平均手牌费用 ③群体 buff |
| **计划经济** | 固定机制：每 5 回合发动一次。预览牌堆顶 3 张并排序 |
| **同志** | 所有受伤且只剩 1 血的单位，攻击力翻倍 |
| **支援** | 固定机制：后排单位可以「支援」前方同列单位。每回合提供 +2 攻击和 -1 血量。回合开始前结算 |

**特色卡牌示例：**
- 「公社」(3 费，建筑)：相邻单位每回合回复 1 血量
- 「五年计划」(5 费，机制卡)：预览牌堆顶 5 张，选 2 张加入手牌
- 「同志冲锋」(2 费，事件)：所有 1 血单位本回合可以再次攻击
- 「后勤支援」(2 费，事件)：中前排单位本回合再次触发支援

## 五、冲突规则

### 5.1 冲突定义

**冲突**：指在规则设计下，无法判断谁该先执行的情况。

### 5.2 冲突类型总览

| 类型 | 名称 | 是否存在 | 处理规则 |
|-----|------|---------|---------|
| 1 | 同命令顺位后排争夺 | 是 | 后排所有者优先 |
| 2 | 同命令顺位中排放置 | 是 | 形成对峙攻击 |
| 3 | 行进 vs 已有单位 | 是 | 按 Rank 顺序执行 |
| 4 | 同命令顺位中排纵向移动 | 是 | 互相攻击 |
| 5 | 连锁死亡 | 是（结算规则） | 每步骤结束即结算 |
| 6 | 同时 buff | 是（结算规则） | 按顺序计算，可叠加 |

### 5.3 详细规则

**冲突 1：同命令顺位后排争夺**
```
双方同命令顺位，计划放置到同一后排格子：
→ 后排所有者优先执行（Rank 1）
→ 先放置者占据位置
→ 后放置者放置失败，卡牌返回手牌
```

**冲突 2：同命令顺位中排放置**
```
双方同命令顺位，计划放置到同一中排格子：
→ 双方单位都放置
→ 立即互相攻击一次（对峙攻击）
→ 存活者占据位置
```

**冲突 3：行进 vs 已有单位**
```
单位已存在，对手计划行进到该位置：
→ 先按照 Rank 顺序执行
→ 如果同 Rank，则同时攻击
→ 如果已有单位离场，则行进单位占据目标位置
→ 如果已有单位存活，则行进失败，返回原位置
```

**冲突 4：同命令顺位中排纵向移动**
```
双方单位同命令顺位，同时计划纵向移动到中排同一位置：
→ 互相攻击一次
→ 若仅剩 1 方存活，则存活方占据目标位置
→ 其他情况（双方存活或双方死亡），双方各占原位
```

**冲突 5：连锁死亡（结算规则）**
```
A 死亡 → 触发 B 效果 → C 死亡 → ...
→ 每有单位死亡，本执行步骤结束即生效和结算
→ 人口损失在回合结束时一次性扣除
```

**冲突 6：同时 buff（结算规则）**
```
多个单位同时触发 buff：
→ 按照顺序计算
→ 可以叠加
```

## 六、撤退机制

```
执行阶段，单位可以选择撤退：

撤退规则：
- 前排 → 中排空位：允许
- 中排 → 后排空位：允许
- 后排 → 不可撤退
- 撤退后本回合不能攻击
- 攻击过的单位，本回合不可撤退

战术用途：
- 保存受伤单位
- 让出关键位置
- 重新部署防线
```

## 八、游戏流程（详细）

### 8.1 回合结构

```
┌─────────────────────────────────────────┐
│           回合开始                       │
│  1. 充满黄金，抽卡 2 张                   │
│  2. 结算先于命令开始的效果               │
│     （如：增加上轮带来的利息）            │
├─────────────────────────────────────────┤
│           战术阶段                       │
│  1. 命令行动：下达多个命令（有时限 3 分钟） │
│     - 放置单位命令                       │
│     - 策划事件命令                       │
│     - 部署非建筑单位命令                 │
├─────────────────────────────────────────┤
│           战争阶段                       │
│  1. 按命令顺序自动执行双方命令            │
│  2. 战斗结算                            │
├─────────────────────────────────────────┤
│           回合结束                       │
│  1. 结算回合外效果                       │
│     （如：计算本轮利息，赋予下个回合）    │
└─────────────────────────────────────────┘
```

### 8.2 胜利条件
